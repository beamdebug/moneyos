# MoneyOS

MoneyOS เป็นแอปการเงินส่วนตัวที่เปิดจากเว็บโฮสต์แบบ static หรือจากไฟล์ HTML บนคอมพิวเตอร์ได้ โดยไม่เรียก API ของ ChatGPT และไม่ต้องมี Plus

## ข้อมูลอยู่ที่ไหน

ข้อมูลจริงบันทึกใน IndexedDB ของเบราว์เซอร์ แยกตามเว็บไซต์และเบราว์เซอร์ ไม่ส่งข้อมูลการเงินไป GitHub หรือเซิร์ฟเวอร์ ไม่มีระบบซิงก์ระหว่างอุปกรณ์ในรุ่นนี้

## ย้ายจากเว็บเดิม

1. เปิด MoneyOS เว็บเดิมจากเครื่องและเบราว์เซอร์ที่เคยใช้
2. กด **สำรองข้อมูล** เพื่อดาวน์โหลดไฟล์ JSON
3. เปิดเว็บใหม่ แล้วกด **นำเข้าข้อมูล** และเลือกไฟล์นั้น
4. ตรวจจำนวนรายการบนหน้าตรวจสอบ แล้วกด **นำเข้ารายการใหม่**

การนำเข้าไม่เขียนทับรายการที่มีรหัสเดิม และนำเข้าไฟล์เดิมซ้ำแล้วไม่เพิ่มรายการซ้ำ

## ลบข้อมูล

- รายการรับ–จ่าย งบ เป้าหมาย และพอร์ตมีปุ่ม **ลบ** พร้อมหน้าตรวจสอบก่อนยืนยัน
- **ล้างข้อมูลเดือนที่เลือก** ลบรายการรับ–จ่าย งบ และสรุปของเดือนนั้นเท่านั้น
- **ล้างข้อมูลทั้งหมด** ลบทุกเดือน เป้าหมาย พอร์ต และหมวดที่เพิ่มเอง แล้วคงหมวดเริ่มต้นไว้
- การล้างเดือนหรือทั้งหมดเปิดตัวเลือกสำรองข้อมูลไว้ให้ก่อนลบ และต้องพิมพ์ **ลบ** เพื่อยืนยัน
- **ตรวจรายการตัวอย่าง** สำหรับข้อมูลที่ตรงกับตัวอย่างของรุ่นเก่า ต้องเลือกด้วยตนเองก่อนลบ ไม่มีการลบรายการจริงอัตโนมัติ

## เปิดแบบไม่พึ่งบริการใด

รัน `node scripts/build-portable.cjs` เพื่อสร้าง `release/MoneyOS-standalone.html` และ `release/MoneyOS-static.zip`

เปิดไฟล์ HTML บน Chrome หรือ Edge บนคอมพิวเตอร์เพื่อใช้ได้ทันที ส่วนมือถือควรใช้เว็บ HTTPS จาก ZIP แล้วเลือกเพิ่มไปยังหน้าจอโฮม เว็บ HTTPS รองรับใช้งานออฟไลน์หลังเปิดครั้งแรกสำเร็จ

## เผยแพร่บน GitHub Pages

ใช้บัญชี GitHub ของคุณสร้าง repository สาธารณะ `moneyos` นำไฟล์ใน `dist/` ขึ้นไปที่ root ของ repository แล้วเปิด Settings → Pages → Deploy from a branch → main → /(root)

GitHub เผยแพร่เฉพาะโค้ดและไฟล์เว็บ ไม่เผยแพร่ข้อมูลการเงินใน IndexedDB ไฟล์สำรอง JSON ต้องเก็บไว้เป็นส่วนตัว

## ตรวจสอบ

`node scripts/test-moneyos.cjs` ทดสอบการบันทึกกันยายน แก้ไข/ลบย้อนหลัง การเก็บข้อมูลหลังรีเฟรช สำรอง/นำเข้า ล้างเฉพาะเดือน ล้างทั้งหมด และการแสดงผล 6 หน้าตั้งแต่ 320–1440px

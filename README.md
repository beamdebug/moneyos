# MoneyOS

เว็บแอปการเงินส่วนตัวแบบ offline-first ที่ไม่ต้องมี ChatGPT Plus และไม่เรียก ChatGPT API

ข้อมูลการเงินบันทึกใน IndexedDB ของเบราว์เซอร์ ไม่มีระบบซิงก์ระหว่างเครื่อง และไม่อัปโหลดข้อมูลส่วนตัวไป GitHub

## เปิดใช้งาน

เปิด Settings → Pages → Deploy from a branch → main → /(root) แล้ว Save เว็บจะอยู่ที่ https://beamdebug.github.io/moneyos/

หากย้ายจากเว็บเดิม ให้กด สำรองข้อมูล บนเครื่องและเบราว์เซอร์เดิม แล้วนำเข้าไฟล์ JSON ที่เว็บใหม่ เก็บไฟล์สำรองไว้เป็นส่วนตัว ไม่เพิ่มไฟล์ข้อมูลการเงินเข้ามาใน repository นี้

## ความสามารถ

Dashboard, CRUD รับ–จ่าย, รายเดือน, งบ, เป้าหมาย, พอร์ตแบบกรอกราคาเอง, Analytics, Dark mode, สำรอง/นำเข้าข้อมูล, ลบรายการ, ล้างเฉพาะเดือนและล้างทั้งหมด

ไฟล์ใน repository เป็นเว็บ static พร้อมใช้งาน ไม่มีขั้นตอนติดตั้ง dependencies รองรับการเพิ่มไปยังหน้าจอโฮมจาก HTTPS และใช้งานออฟไลน์หลังเปิดเว็บครั้งแรก
